# 抖音观测台 · 分流 · 功能介绍与使用指南

## 1. 这是什么

是一套本地运行的直播间观察工具，适用于你**自有或已获得授权**的直播间。它把直播页面实际公开展示的内容整理为可回看的本地记录，便于筛选、告警和导出。

核心价值是沉淀直播间内真实公开的发言用户信息：

- 页面实际显示的昵称、公开弹幕和发生时间；
- 资料卡确实展示时可保存的真实公开头像；
- 页面实际打开时可回填的公开主页链接；
- 每个直播间独立保存的事件、告警和公开网页快照。

> 不会猜测未公开的抖音号，不读取 Cookie、私信、隐藏接口或其他非公开数据。

## 2. 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | macOS 或 Windows |
| Node.js | 20 或更高版本 |
| 浏览器 | 建议使用已登录的 Chrome，并安装包内浏览器采集器 |
| 网络 | 首次启动需要联网安装运行组件；后续本地观察不依赖云端账号 |

---

## 3. 首次启动与激活

1. Mac 双击 `启动观察台.command`；Windows 双击 `启动观察台.bat`。
2. 第一次启动会自动安装运行组件，请保持窗口开启并等待浏览器打开观察台。
3. 欢迎页会介绍可用能力。点击 **“激活后开始使用”**。
4. 输入卖家通过其他方式单独发送的卡密，点击 **“激活并进入观察台”**。
5. 激活成功后，授权会保存在当前浏览器；同一台电脑通常不需要重复输入。

如果浏览器没有自动打开，请访问：`http://127.0.0.1:8787`。

---

## 4. 主要功能

### 4.1 直播间用户与公开弹幕

- 实时展示已授权页面中实际可见的公开弹幕、系统提示和进场事件；
- 全部事件按 **头像 / 发言人 / 弹幕 / 时间 / 操作** 查看；
- 已获取真实公开头像的发言用户会进入“发言用户列表”；
- 可以从事件最右侧直接按昵称打开抖音站内用户搜索；
- 没有公开头像或主页链接时，系统保持空态，不会用默认头像或昵称推断身份。

### 4.2 独立本地存档

每个新登记的直播链接都会创建独立本地存档，数据不会与其他直播间混在一起。存档包含该链接的事件、告警和公开网页快照；可从观察台下载对应的 `.save.json` 文件。

### 4.3 筛选、关键词告警与 CSV 导出

- 按事件类型筛选公开弹幕、进场事件或系统弹幕；
- 搜索昵称、公开标识或内容；
- 设置关键词，命中后在告警区查看并确认；
- 导出的 CSV 与当前筛选结果一致，适合进一步整理。

### 4.4 公开网页快照与 Firecrawl

你可填写自己的 Firecrawl API Key，为一个公开 URL 保存一次正文快照。该功能用于公开网页资料整理，**不是**实时弹幕监听，也不会复用 Chrome 的登录态。

## 5. 开始观察一个直播间

1. 在顶部“新建直播间采集”输入完整直播链接，例如 `https://live.douyin.com/123456`。
2. 点击 **“创建存档并打开直播页”**，观察台会先建立该链接的独立本地存档。
3. 使用 Chrome 打开或刷新对应直播页，并确保该页面属于你自有或已授权观察的范围。
4. 按下一节加载浏览器采集器。页面出现新的公开弹幕后，事件会实时写入观察台。
5. 在“全部事件”“发言用户列表”“关键词告警”中查看和整理结果。

暂停当前房间后，不再接收新的事件；恢复后可继续观察。

---

## 6. 安装 Chrome 浏览器采集器

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角 **“开发者模式”**。
3. 点击 **“加载已解压的扩展程序”**，选择本包内的 `extension` 文件夹。
4. 回到已经登记的直播页面并刷新一次。
5. 进入观察台的“采集器连接与使用说明”，确认出现“采集器已连接”。

默认会自动识别常见的页面公开昵称和弹幕结构。只有在状态提示“候选节点为 0”或没有写入新事件时，才需要在采集器连接区按页面实际结构填写手动 CSS 选择器。

---

## 7. Firecrawl API Key 怎么填

1. 在观察台“新建直播间采集”区域找到 **“你的 Firecrawl API Key”**。
2. 输入你自己的 Firecrawl Key；它只保存在当前浏览器本地。
3. 生产环境的公开网页抓取必须使用你自己的 Key，观察台不会把该 Key 写入本地数据文件或日志。

没有 Firecrawl Key 不影响直播页采集器记录公开弹幕；只是无法使用公开网页快照功能。

---

## 8. 数据保存与隐私边界

- 运行数据保存在本包的 `data/` 目录；请定期自行备份。
- 每个直播链接拥有自己的 `.save.json` 存档和头像目录。
- 卡密明文不在本包中，运行数据只保存不可逆校验信息。
- 请只用于自有或已获得授权的直播间，并遵守平台规则和适用法律。

## 9. 常见问题

### 双击后没有打开页面

- 确认已经安装 Node.js 20 或更高版本；
- 首次启动请等待运行组件安装完成；
- 在浏览器手动打开 `http://127.0.0.1:8787`；
- 不要关闭启动窗口，关闭后本地服务会停止。

### 激活失败

- 确认卡密没有多余空格、输入正确；
- 检查卡密是否已超过可激活设备数；
- 联系卖家确认卡密有效期和设备数。

### 直播页没有新数据

- 确认已登记正确的直播链接，且房间状态为“观察中”；
- 在 Chrome 扩展页确认采集器已启用；
- 刷新直播页后等待一条新的公开弹幕；
- 在“采集器连接与使用说明”检查连接状态和候选节点数。

### 看不到某个用户的头像或主页

这表示页面没有公开展示可获取资料，或资料卡没有成功出现。系统不会猜测账号或伪造头像；该用户的公开弹幕仍会保留在事件列表中。
